How this map is generated

It starts from a single tile and works outwards, each new tile rolled from the terrain of the one before it. See this write-up or the 1st edition Dungeon Masters Guide (p.173) for the tables.

Changes from the original tables

Scrub is called Brush, Pond is Water and Depression is Valley.
